look/feel-числа — новые поля `GameFeelConfig` (решение 10a).

### 3.2. Кукла-Сборщик в Main.unity

Иерархия (конвенция Р12 Фазы А): корень `Player` (как есть: `PlayerView`) →
чайлд `Visual` = инстанс `UAL1_Standard.fbx` (`PrefabUtility.InstantiatePrefab`
в бутстрапе), на нём `Animator` (`PlayerAnimator.controller` из `_Ring`,
`applyRootMotion = false`). Капсульные `MeshRenderer`/`MeshFilter` корня
удаляются бутстрапом (self-heal уже закоммиченной сцены); материал
`PlayerEmissive` остаётся на диске (грейбокс-фолбэк, Фаза А §8).

Новый компонент **`PlayerVisual`** (Presentation, на корне `Player`) — все
анимационные обязанности; `PlayerView` не меняет зону ответственности
(позиция корня из интерполяции), но перестаёт вращать корень (§3.2.2).

1. **Speed (контракт app-5g6):** `Speed = clamp(length(RenderCurr.Player.Vel) /
   World.Config.Hero.MaxSpeed, 0, 1)`; `Animator.SetFloat(SpeedId, value,
   dampTime, Time.unscaledDeltaTime)`; `dampTime` — `GameFeelConfig`. Чтение
   конфига — паттерн `ViewRegistry` (`_runner.World.Config…`), SO напрямую
   не читается. Хеш-имена параметров/стейтов — кэшированные
   `Animator.StringToHash` (ноль аллокаций в кадре).
2. **Поворот корпуса — к движению:** `PlayerView` больше не пишет
   `transform.rotation` (правка Э1-класса санкционирована этой спекой);
   `PlayerVisual` поворачивает `Visual` к направлению `Vel` (slerp со
   скоростью °/сек из `GameFeelConfig`) при `length(Vel) >` порога; ниже
   порога — поворот не меняется (idle держит последнее направление).
3. **Прицел (6a):** Aim-слой держит позу (`Pistol_Aim_Neutral`, вес 1 —
   как сгенерировано); горизонталь — процедурный yaw кости `spine_02`/`chest`
   (фактическое имя кости — из иерархии куклы, фиксируется планом) к
   `AimProvider.CurrentAimSimPos` в `LateUpdate` ПОСЛЕ Animator (порядок
   гарантирован: Animator обновляется в Update-фазе при `applyRootMotion=false`
   и обычном `updateMode`). Угол клампится (`GameFeelConfig`, дефолт ±80°);
   за пределами — доворот всем корпусом не делаем (ноги ведёт движение,
   решение 6a осознанно допускает редкие «стрельба вполоборота»).
4. **Выстрел:** по `ProjectileFired` с `Owner == Player` — `CrossFade` в
   `Pistol_Shoot` Aim-слоя, по завершении — обратно в `Pistol_Aim_Neutral`
   (или normalized-time выход; без новых транзишенов в ассете контроллера —
   кодом, чтобы не пересобирать сгенерированный контроллер).
5. **Дэш (7a):** пока в снапшоте активен дэш (поля `PlayerState` дэша),
   `Visual` наклоняется в `DashDir` на угол из `GameFeelConfig`
   (процедурный лин, плавный вход/выход); Roll-стейт контроллера остаётся
   невостребованным (заготовка Фазы А, вреда нет).
6. **Смерть/рестарт (4a):** `PlayerDied` → `CrossFade("Death")` (Death01,
   one-shot, замирает на последнем кадре — `loopTime=false` уже выставлен
   постпроцессором); `WorldRestarted` → сброс в `Locomotion` + сброс
   спайн-yaw/наклона. События — через `SimEventRouter` (новый слот
   `_playerVisual`, П-1: подписка на `TicksFlushed` не добавляется);
   `WorldRestarted` — прямая подписка (паттерн `ViewRegistry.Clear`).
7. **Пушка (8a):** инстанс `Gun_*` (идентификатор — константа бутстрапа,
   стартово `Gun_Pistol`, если есть в отборе; иначе первый по алфавиту —
   факт зафиксирует план по `INSPECTION.md`/содержимому `SciFiEssentialsKit/`)
   крепится бутстрапом чайлдом к кости правой кисти (`hand_r`) куклы;
   локальный офсет/поворот — константы бутстрапа (подгонка на вехе).
   `MuzzleFlashView`/трейсеры не трогаются (позиции — из событий, инвариант Э1).
8. **Масштаб куклы:** `GameFeelConfig.PlayerVisualScale` (дефолт 1);
   `CapsuleOffset` (up·1f) в `PlayerView` заменяется на 0 (пивот куклы — в
   ногах, корень — на земле). `AimProvider`/камера не меняются.

### 3.3. Мехи на Chaser/Gunner

- **Префабы:** `MobChaserView.prefab` (George) и `MobGunnerView.prefab`
  (Leela) — создаются `StageOneSceneBootstrap` (existence-guard, как все
  префабы Э1): корень с `MobView` (+ новый `MobVisual`) без коллайдера,
  `Visual`-чайлд = инстанс меха, `Animator` = контроллер Фазы А
  (`GeorgeAnimator`/`LeelaAnimator`), `applyRootMotion=false`. Маппинг
  «архетип → FBX + контроллер» — одна таблица-константа в бутстрапе (1b).
  Старый `MobView.prefab` (капсула) остаётся на диске фолбэком, из сцены
  и пулов уходит.
- **`ViewRegistry` (11a):** пул и словарь — на архетип: `_chaserPrefab`/
  `_gunnerPrefab`, `RentMob(MobType)`, возврат в пул своего типа. Диффалка
  по Id не меняется; `Bind`-контракт не меняется. Ёмкости — от
  `ArenaConfig.MaxMobs` (как сейчас; предразбиение по типам не требуется —
  пулы растят себя `Instantiate` при недоборе, паттерн Э1).
- **Новый компонент `MobVisual`** (на корне префабов, сосед `MobView`):
  ведёт Animator меха от `MobState` в `Sync`-цикле (`ViewRegistry` зовёт
  рядом с `MobView.Sync`, П-1 — без новых подписчиков):
  - локомоция: `CrossFade` `Idle`/`Walk`/`Run` по `length(Vel)` с двумя
    порогами (`GameFeelConfig`); стейты контроллеров Фазы А уже названы
    короткими именами клипов (`ClipsOf`-ключи);
  - Chaser: `Ai == Telegraph` → `CrossFade("Punch")` (один раз на вход в
    стейт, ретриггер по смене `Ai`); `Recover` → `Idle`;
  - Gunner: `Ai == Fire` → `CrossFade("Shoot")` на тик выстрела (вход в Fire);
    `Reposition` → локомоция;
  - смена стейта — только при изменении `Ai`/порога (кэш последнего),
    без `CrossFade` каждый кадр; хеши стейтов кэшированы.
  - Тайминги клипов паков ≠ таймингам симуляции — осознанная визуальная
    аппроксимация (телеграф-пульс эмиссии остаётся главным телеграфом);
    итерации — на вехе.
- **Ориентация:** Chaser — `Visual` к направлению `Vel` (как кукла);
  Gunner — к игроку (`RenderCurr.Player.Pos`) в `Reposition`/`Fire`
  (страйф боком — честно), иначе к `Vel`. Поворот — slerp °/сек из
  `GameFeelConfig` (общая константа с куклой не обязательна — поле на мобов
  своё, вкус вехи).
- **Масштабы/офсет:** `GameFeelConfig.MechVisualScale` (дефолт 0.4 — число
  вехи-1 превью); `MobOffset` (up·1f) → 0 (пивоты мехов — в ногах).
  Footprint меша к `MobConfig.Radius` не привязываем формулой — вкус вехи.

### 3.4. Эмиссия и game-feel-инварианты (9a)

- `MobView.Bind`: базовая эмиссия мехов — `Color.black` (константы
  `ChaserAccent`/`GunnerAccent` уходят); телеграф-пульс, глинт ганнера,
  `FlashAccent`-хит-флэш — без изменений (аддитивны поверх чёрной базы).
- Инвариант Э1 подтверждается на реальных мешах (веха Б2): `Flash`/`Sync`
  пишут один `MaterialPropertyBlock` во ВСЕ `Renderer`'ы (включая
  `SkinnedMeshRenderer` мехов — `_renderers` собирается в `Awake`,
  `GetComponentsInChildren<Renderer>(true)` уже покрывает чайлдов);
  искры — от `e.Pos`; hitstop — интерполяцией (`RenderPrev/Curr/Alpha`) —
  ничего из этого от конкретных мешей не зависит.
- URP/MPB: материалы мехов — `ImportViaMaterialDescription`-URP Lit со
  слотом `_EmissionColor` (проверено Фазой А); `_EMISSION`-кейворд для MPB
  не требуется догонять на материалах паков — если на вехе флэш не виден,
  это баг-находка вехи (запасной ход — ремап-материал в `_Ring/Materials`
  с `EnableKeyword`, паттерн А5 Фазы А), не молчаливый фикс.

### 3.5. Трупы мехов (5a)

- Вместо одного капсульного `Corpse.prefab` — `CorpseChaserView`/
  `CorpseGunnerView` (existence-guard в бутстрапе): `CorpseView` + `Visual` =
  мех + `Animator`; при спавне трупа — `CrossFade("Death")`, по завершении
  клипа (`normalizedTime ≥ 1`) `Animator.enabled = false` (нулевая стоимость
  дальше; чек — в `CorpseView.Update`, который уже существует для фейда).
- `PersistentPropsDirector`: пул трупов — на архетип (`SimEvent.MobType`
  есть в `MobDied`); FIFO-лимит общий (`GameFeelConfig`, как в Э1).
  Ориентация: направления смерти в `MobDied` нет, а директор вьюх не видит
  (П-1) — yaw трупа = детерминированная функция от `EntityId` (косметика без
  RNG-потребления и без новых полей событий). Капсульный `Corpse.prefab`
  остаётся фолбэком на диске.
- MPB-тинт затухания `CorpseView` работает по всем renderer'ам (как MobView).

### 3.6. Бутстрап, EditorBootstrapUtils (Р9), сцена

- Все правки сцены/префабов — ТОЛЬКО `StageOneSceneBootstrap.Apply`
  (идемпотентный, self-healing; сцены руками не редактируются). Новые шаги:
  Visual-чайлд куклы у `Player` (+удаление капсульного рендера корня,
  self-heal), `PlayerVisual` + провода (runner, aimProvider, gameFeel,
  animator), пушка в кисть, префабы мехов/трупов ×4, перепровод
  `ViewRegistry` (`_chaserPrefab`/`_gunnerPrefab`), слот
  `SimEventRouter._playerVisual`, маркер-ключ синка `GameFeelConfig`
  переводится на новейшее поле Фазы Б (конвенция Э1, §строка 245 бутстрапа).
- **`EditorBootstrapUtils`** (`Scripts/Editor/EditorBootstrapUtils.cs`):
  извлекаются дублирующиеся guard-примитивы обоих треков — `EnsureFolder`,
  `FindRootObject`, `SetRef`, `RemoveCollider`, `GetOrCreate<T>`-паттерн
  материалов/префабов (фактический список — по пересечению
  `StageOneSceneBootstrap` ↔ `ThirdParty*`/`AssetPreview*`-бутстрапов,
  зафиксирует план); оба семейства бутстрапов переводятся на утилиты;
  поведение и идемпотентность — бит-в-бит (гейт: повторный `Apply` всех
  четырёх бутстрапов → пустой `git diff`).
- `AssetPreview.unity`/превью-бутстрап не трогаются (кроме перехода на
  утилиты); секция ассет-трека handoff'а обновится по итогам (наша сессия).

### 3.7. GameFeelConfig: новые поля (10a)

Все дефолты — стартовые значения вех, hot-tweak через `OnValidate` (механизм
Э1 уже есть; Simulation эти поля не читает — только Presentation):

`PlayerVisualScale=1`, `MechVisualScale=0.4`, `SpeedDampTime≈0.1`,
`VisualTurnDegPerSec≈720` (кукла), `MobTurnDegPerSec≈540`,
`MobWalkSpeedThreshold`/`MobRunSpeedThreshold`, `AimYawClampDeg=80`,
`DashLeanDeg≈18`, `DashLeanInOutSeconds`. Точный список/имена финализирует
план; маркер-ключ синка бутстрапа = последнее добавленное поле (конвенция Э1).

## 6. Риски

- Пивоты/оси FBX (кукла или мехи повернуты в осях пака) — лечится локальным
  поворотом `Visual` в префабе/бутстрапе (константа), не кодом кадра.
- Спайн-yaw может бороться с позой Aim-слоя (двойной поворот руки) — кламп
